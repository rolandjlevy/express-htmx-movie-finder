Search films as you type.

Every keystroke asks the server for results. It replies with ready-made HTML and the page updates without reloading.

See the code

The form sends a GET request to /search as you type. Express asks OMDb and returns HTML, and HTMX swaps it into the results area. A few lines of script keep the address bar in sync, so a search can be shared.

Markup (trimmed)

<form
  hx-get="/search"
  hx-trigger="input delay:500ms,
    search, submit"
  hx-sync="this:replace"
  hx-target="#result">
  <input type="search"
    name="q">
</form>
<div id="result"></div>

Server (simplified)

// index.js (simplified)
app.get('/search', handler);

async function handler(req, res) {
  const { q } = req.query;
  const films = await search(q);
  res.send(films.map(card).join(''));
}
